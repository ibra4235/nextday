# Nextday

iOS app. The opening screen shows the egg, large and centered.

Open `ios/Nextday.xcworkspace` in Xcode.

Copy follows the device language. English is used when the device language is English. Turkish is used otherwise.

On a Mac, install pods once before the first build:

```bash
cd ios
pod install
```

For the Expo dev server:

```bash
npm install
npx expo start
```
